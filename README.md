# CampusHub

CampusHub is a full-stack student opportunity platform that helps students discover and track internships, scholarships, and other opportunities through a centralized dashboard.

## Live Demo

[CampusHub](https://campushub-xi-six.vercel.app/)

## Features

- User registration and login
- JWT-based authentication
- Student dashboard
- Browse student opportunities
- Application tracking
- Application status management
- User profile management
- RESTful backend APIs
- MongoDB-based data persistence
- Responsive React frontend

## Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- React Router

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs

### Deployment

- Vercel — Frontend
- Render — Backend
- MongoDB Atlas — Database
